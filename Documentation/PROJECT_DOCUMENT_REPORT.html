1. Executive Summary

The Hostel Room Allocation and Management System (HMS) is an enterprise-grade full-stack web application designed to digitize and automate student residential administration at NIT Calicut. The system eliminates manual paperwork, spreadsheet tracking, and allocation delays by providing real-time room inventory management, online student room requests, approval workflows, and two-way warden communications.

Room Inventory

Real-time room occupancy analytics across all hostel blocks (GIRLS HOSTEL, Block B through F).

Student Self-Service

Self-registration, profile management, allocation requests with special preferences, and status tracking.

Warden Command Center

One-click room allotment, vacancy management, student roll roster, and campus broadcasts.

3. System Architecture

The system is architected as a clean, decoupled 3-Tier Web Application:

  • Presentation Layer (SPA): Vanilla HTML5, CSS3, and JavaScript Single Page Application that dynamically switches views (Auth View, Student Portal, Manager Portal) without page reloads.
  • Application & API Layer (Node.js/Express): RESTful API server running on http://localhost:5000 with CORS, session authentication headers, and business logic controllers.
  • Data Persistence Layer (SQLite3): File-based relational database running in Write-Ahead Logging (WAL) mode for maximum concurrency and data safety.
Cache-Busting & Port 5000 Isolation: To prevent collisions with existing web applications or browser service-workers on port 3000, the server runs on Port 5000 and serves Cache-Control: no-store headers, while the client automatically unregisters any lingering service workers.
